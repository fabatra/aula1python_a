2️⃣ Relembrando os Comandos Básicos

Antes de aceitar os desafios, relembre a função de cada comando que você usará no código:

🔹 Tomada de Decisão (if / elif / else)

Permite que o programa faça perguntas e tome caminhos diferentes dependendo da resposta:

  • if (SE): Avalia a primeira condição.
  • elif (SENÃO SE): Testa uma nova condição caso a anterior seja falsa.
  • else (SENÃO): Define o caminho padrão quando nenhuma condição for atendida.

🔹 Repetição Contínua e Emergência (while True e break)

  • while True: Cria um ciclo de execução contínuo (o robô fica rodando e lendo sensores sem parar).
  • break: Interrompe a repetição imediatamente (funciona como o botão de parada de emergência).

🔹 Proteção contra Dados Corrompidos (try / except)

  • try: Tenta converter ou processar um dado digitado.
  • except ValueError: Evita que o programa trave caso o usuário digite texto em vez de números.

3️⃣ Bateria de Desafios Práticos de Programação

Desenvolva cada um dos códigos abaixo no Programiz para validar o funcionamento do seu algoritmo.

🧪 Desafio 1: Validador de Bateria do Robô

Cenário: O seu robô precisa checar o nível da bateria antes de sair para uma entrega e avisar a condição ao operador.

Sua missão:
  1. Peça para o usuário digitar o nível de bateria atual (um número de 0 a 100).
  2. Converta a entrada para número inteiro usando int(input()).
  3. Se a bateria for maior que 70, exiba: 🔋 Bateria cheia! Pronto para rodar.
  4. Se estiver entre 30 e 70, exiba: 🪫 Bateria média. Atenção no percurso.
  5. Se for menor que 30, exiba: 🚨 Bateria fraca! Retorne à estação de carga.
🧪 Desafio 2: Monitor de Temperatura do Motor

Cenário: O motor do carrinho não pode ultrapassar a temperatura limite de 80 °C durante o funcionamento.

Sua missão:
  1. Crie um laço de repetição contínuo usando while True:.
  2. Dentro do laço, peça para o usuário digitar a temperatura atual do motor (°C).
  3. Se a temperatura for maior que 80, exiba 🔥 ALERTA: Superaquecimento! Desligando motores... e encerre o laço usando break.
  4. Caso contrário, exiba 🟢 Motor operando normalmente... e continue pedindo novas leituras.
🧪 Desafio 3: Filtro de Ruído no Sensor

Cenário: Um cabo solto pode fazer o sensor enviar letras ou textos vazios. O código não pode travar!

Sua missão:
  1. Solicite a leitura da distância do sensor usando input().
  2. Use a estrutura try: para tentar converter o texto digitado em um número inteiro com int().
  3. Se a conversão for bem-sucedida, exiba: ✅ Leitura Válida: X cm.
  4. Use except ValueError: para capturar o erro e exibir: ⚠️ Erro de leitura: Sensor enviou dado corrompido!.
🧪 Desafio 4: Sorteador de Rotas de Entrega

Cenário: O carrinho de entrega deve escolher um destino aleatório a cada saída da garagem.

Sua missão:
  1. Importe a biblioteca de sorteios adicionando import random na primeira linha do código.
  2. Sorteie um número inteiro entre 1 e 3 usando random.randint(1, 3) e guarde em uma variável.
  3. Se o número sorteado for 1, exiba: 🚚 Rota 1: Entregar no Laboratório 1
  4. Se for 2, exiba: 🚚 Rota 2: Entregar na Biblioteca
  5. Se for 3, exiba: 🚚 Rota 3: Entregar na Secretaria
🧪 Desafio 5 (Combo Final): Alarme Sonoro de Aproximação

Cenário: Crie um sistema completo de ré/aproximação em malha fechada com proteção contra erros.

Sua missão:
  1. Crie um laço contínuo com while True:.
  2. Peça a distância do obstáculo em centímetros.
  3. Trate entradas inválidas usando try/except ValueError:. Se o usuário errar a digitação, exiba um aviso e use continue para recomeçar o loop.
  4. Se a distância for menor ou igual a 20 cm, exiba 🔴 FREIO DE EMERGÊNCIA ATIVADO! e encerre com break.
  5. Se estiver entre 21 cm e 50 cm, exiba: 🟡 Cuidado: Obstáculo se aproximando!
  6. Se for maior que 50 cm, exiba: 🟢 Caminho livre
